## 一、核心认知与工具准备
### 1.1 剪辑核心三步法
所有视频剪辑都可以拆解为三个标准化环节，AI剪辑完全沿用该逻辑，降低学习门槛：
1.  **粗剪**：剪掉口误、气口、重复表述，保留有效视频片段
2.  **字幕**：生成带时间戳的字幕文件，对齐视频内容
3.  **包装**：添加动画、视觉素材、风格化效果，完成视频整体包装
![](images/screenshot_000_fab0e28b-d833-4b68-9465-626059998c44.jpg)

### 1.2 所需工具清单
本次流程共需要4款工具+待剪辑原视频，Codex作为核心智能体，负责串联调度所有工具的全流程：
| 工具名称 | 核心作用 |
|---------|---------|
| 剪映 | 完成视频初步粗剪，低成本去除无效片段 |
| WhisperX | 自动生成带精准时间戳的SRT字幕文件 |
| HyperFrames | 完成视频动画渲染、视觉包装、成片导出 |
| Codex | 核心调度工具，理解指令、调用工具、执行修改、输出结果 |
![](images/screenshot_001_06861e4f-129d-41cf-bcf1-e9e47555d044.jpg)

## 二、分步实操教程
### 2.1 第一步：剪映完成视频粗剪
Codex对口误、气口、重复表述的识别精度有限，因此先用剪映完成低成本的初步粗剪，降低后续AI处理的出错概率。
操作步骤：
1.  打开剪映，导入待剪辑的原视频到时间轴
![](images/screenshot_002_e85c5177-fde7-4104-b61e-ef77a4f2143a.jpg)
2.  点击剪映「智能剪口播」功能，AI自动识别视频中的无效片段
![](images/screenshot_003_79b9dd7f-1afb-4864-a4d7-9d1035257ceb.jpg)
3.  手动校验剪辑结果：
    - 核对自动识别的语气词、停顿、重复表述是否准确
    - 对于漏识别的无效内容，选中对应字幕/片段直接删除即可
![](images/screenshot_004_ccfc3867-dd55-4631-bd7f-3e093ff38a1f.jpg)
4.  确认粗剪无误后，将视频导出到指定的项目文件夹，关闭剪映
![](images/screenshot_005_35ce2281-0485-43c8-824b-0ba3ad5f9d19.jpg)

### 2.2 第二步：Codex调用WhisperX生成字幕
操作步骤：
1.  打开Codex，将工作目录设置为刚才的项目文件夹，导入粗剪完成的成片
![](images/screenshot_006_515ff11e-a089-4969-bbfa-1cb2e44a3269.jpg)
2.  向Codex发送指令：
    ```
    这是我剪好的视频，请用WhisperX帮我生成带时间点的SRT字幕文件，保存到同一个文件夹
    ```
![](images/screenshot_007_bc567182-261f-4e23-8aba-5b8a4abf927a.jpg)
3.  工具依赖处理：如果本地未安装WhisperX，无需手动操作，直接告知Codex帮你完成安装配置即可
![](images/screenshot_008_ff7f505d-961b-41dc-914b-c3052f8027f0.jpg)
4.  等待执行完成，打开项目文件夹，确认已经生成对应SRT字幕文件
![](images/screenshot_009_3b85b763-a128-44f4-ac49-343caaa4d83e.jpg)

### 2.3 第三步：拆解视频内容，规划动画与字幕
这一步的目的是让AI识别内容逻辑，区分信息权重：核心观点、数据、流程适合做动画强化，过渡表述、口语化内容仅保留字幕即可。
操作步骤：
向Codex发送指令：
```
请根据这个视频和SRT字幕，帮我拆解内容的重点，告诉我哪些地方适合做动画，哪些地方只需要保留字幕
```
等待Codex输出内容拆解结果，确认重点标注、处理建议符合你的内容逻辑。
![](images/screenshot_010_570b4a9f-1e57-4323-b267-86c23be920fa.jpg)

### 2.4 第四步：生成可视化风格预览，确定包装风格
使用HTML格式做预览的优势：HTML是AI最容易生成的可视化格式，生成速度快、消耗Token少，无需渲染即可直观看到静态视觉效果。
操作步骤：
1.  向Codex发送指令：
    ```
    请基于视频画面和内容重点，帮我生成三种可视化的HTML风格预览，不要只给我文字描述，我要能在浏览器里看到效果，每一种风格都要有展示的标题、重点词、卡片、贴片、流程、数据等常见的元素
    ```
![](images/screenshot_011_0f48e2f8-f1d5-4971-8ce2-0a81244c08c2.jpg)
2.  等待生成完成后，打开输出的HTML文件，查看三种预设风格的视觉效果
![](images/screenshot_012_39790a39-bfdf-43a9-946a-94e495ac107b.jpg)
3.  风格调整：如果对预设风格不满意，直接向Codex提出具体修改要求即可，示例指令：
    ```
    这三种风格都不好看，尤其是第三种，我是横屏视频，你做成了竖版不符合要求。请按照横屏样式，给我做一版科技风的预览
    ```
![](images/screenshot_013_4fada5ad-d78c-4337-9a5f-9cbe84e9422f.jpg)
4.  重复调整流程，直到静态风格的配色、布局、元素设计符合你的预期
![](images/screenshot_014_e2925131-289e-4e41-9bc9-c4434d0714af.jpg)

### 2.5 第五步：生成短Demo，校验动态效果
静态预览满意不代表动态效果符合要求，因此先生成10秒左右的短Demo校验动效，避免全片渲染后修改浪费时间。
操作步骤：
1.  安装HyperFrames插件（未安装时执行）：打开Codex插件市场，搜索`HyperFrames`，点击安装即可
![](images/screenshot_015_d1c15fd1-d3af-42fc-9ed3-0bccaa3084b9.jpg)
2.  向Codex发送指令：
    ```
    我认为这个版本的风格不错，你用HyperFrames帮我生成一个10秒左右的Demo，不要直接做完整版，我要先看效果，再决定是否要修改
    ```
![](images/screenshot_016_c48e3c43-9c92-42bf-8e91-5f0c7ef11ab3.jpg)
3.  打开生成的Demo视频，校验动态效果：
    - 动画转场是否自然流畅
    - 字幕、信息卡片的出现时间是否和台词完全同步
![](images/screenshot_017_22074a5d-3a8b-42f4-a6a7-7662be865fc2.jpg)
4.  Demo调整：如果发现问题，向Codex提出具体修改要求，示例指令：
    ```
    动画效果没问题，但是有些组件出现的过早，我希望视频效果是跟内容、台词完全同步的
    ```
    等待Codex重新生成Demo，重复校验流程，直到动态效果符合预期。
![](images/screenshot_018_829a65a1-5809-438a-993a-96c086d27f12.jpg)

### 2.6 第六步：生成完整预览，做最终全片校验
Demo确认无误后，不要直接导出成片，先生成完整的Studio预览，做全片的最终校验。
操作步骤：
1.  向Codex发送指令：
    ```
    这个Demo可以了，请用HyperFrames按这个风格生成完整的视频Studio预览，先不要导出MP4，我要在预览里去检查时间轴、文字、动画以及画面遮挡有没有问题
    ```
![](images/screenshot_019_53b4c9c2-10f4-4623-9475-5cfe4b5b4810.jpg)
2.  打开生成的Studio预览链接，该预览和专业剪辑软件界面一致，可以查看画面、时间轴、所有素材特效的排布
![](images/screenshot_020_008e385d-ec20-4479-8eed-782249640bc6.jpg)
3.  全片播放校验：检查全片的字幕同步、动画效果、画面遮挡、内容匹配度，如果有问题继续向Codex提出修改要求，直到全片效果符合预期。
![](images/screenshot_021_fd3140a2-1a46-4474-9ddb-ca5a01fbaaea.jpg)

### 2.7 第七步：导出最终成片
预览确认无误后，执行最终导出：
向Codex发送指令：
```
Studio预览我确认没有问题，请帮我导出最终的MP4文件，放到项目的文件夹里
```
等待导出完成，即可得到剪辑、包装全部完成的可发布成品视频。
![](images/screenshot_022_f47e7419-ac25-4874-96c3-453dfaa4566d.jpg)

## 三、进阶效率方案：一键剪辑Skill
上述分步操作逻辑清晰，但每次剪辑都需要逐步发送指令，效率较低；可以使用预制的一键剪辑Skill，实现全流程自动化。
1.  Skill介绍：`jianji-workflow`（口播视频一键剪辑技能），内置了所有剪辑规则、动画逻辑、风格配置，无需人工逐步调试指令
![](images/screenshot_023_19e19e22-4278-4a66-b011-8def8bc03d21.jpg)
2.  使用方法：
    - 运行该Skill，直接上传待剪辑的视频
    - 到风格确认环节，从预设风格中选择你想要的包装风格（提供知识黑板风、社媒爆点风、科技风等多种预设）
    ![](images/screenshot_024_3e2faff4-413b-4332-a578-d36a172c49aa.jpg)
    - AI自动执行全流程，完成粗剪、字幕生成、风格包装、视频渲染，直接输出可发布的成品视频
![](images/screenshot_025_ff120920-5a3c-440f-81e0-fcf2ebf6261e.jpg)
优势：所有动画逻辑、字幕同步规则、元素配置都已经预制完成，仅需上传视频、选择风格两步即可完成剪辑，效率提升显著。

## Reference
1.  **工具获取**
    - Codex：OpenAI官方推出的AI智能体平台
    - HyperFrames：Codex插件市场可直接搜索安装
    - WhisperX：Codex可自动完成安装配置，无需手动操作
    - 剪映：官方渠道下载即可
2.  **指令撰写原则**
    - 明确任务目标，避免模糊描述
    - 明确限制条件（例如"不要直接导出完整版，我要先看Demo"）
    - 效果描述尽量具体，例如"科技风"、"16:9横屏比例"
3.  **校验原则**
    按照「静态风格→短Demo动态→全片预览→最终导出」的顺序逐步校验，每一步确认无误再进入下一步，避免全片渲染后再修改浪费时间。
